Drop your existing backend/ modules into this folder (from your local
VS Code project — they weren't part of this upload):

  backend/__init__.py     -> (can be empty, just makes "backend" a package)
  backend/config.py       -> GEMINI_API_KEY, LLM_MODEL, UPLOAD_DIR
  backend/rag.py          -> add_file_to_rag(), retrieve_documents(), generate_answer()
  backend/vectorstore.py  -> get_document_count()
  backend/placement.py    -> process_placement_message()

app.py imports from all four of the modules above.

(Previously app.py called is_placement_question / answer_from_current_chat_document /
general_gemini_answer without importing them — that's fixed now; app.py defines
all three itself, so no import changes are needed there.)
